Operational Parameters

Does any investigative data leave India?

add

No. The entire KSP Intel architecture is deployed on sovereign, on-premise infrastructure. No external APIs or foreign servers process any part of the dataset.

How is bilingual input processed securely?

add

We utilize a localized SLM (Small Language Model) fine-tuned specifically for Kannada-English code-switching and local law enforcement terminology.

Can we integrate legacy FIR databases?

remove

Yes, the platform includes automated ETL pipelines designed to ingest, sanitize, and vectorize unstructured historical records spanning over 15 years.

What happens if a node loses connectivity?

add

The system supports partitioned offline execution. Field agents can continue logging entities locally, which automatically encrypt and sync once connectivity is restored.

Who manages the clearance protocols?

add

Clearance tiers are programmatically bound to the internal state directory. Tier escalations require cryptographic signing by a commanding officer.
